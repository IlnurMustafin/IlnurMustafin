# AI Chat — Multi-Provider AI Chat App

[![Flutter](https://img.shields.io/badge/Flutter-3.11+-02569B?logo=flutter&logoColor=white)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.11+-0175C2?logo=dart&logoColor=white)](https://dart.dev)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**AI Chat** — это мобильное приложение для общения с AI-моделями через API VSEGPT и OpenRouter. Поддерживает несколько провайдеров, выбор моделей, аналитику использования и безопасную аутентификацию по PIN-коду.

## ✨ Возможности

### 🔐 Система аутентификации
- **Поддержка двух провайдеров**: VSEGPT (`sk-or-vv-...`) и OpenRouter (`sk-or-v1-...`)
- **Автоматическое определение провайдера** по префиксу ключа
- **Проверка баланса** через API каждого провайдера перед активацией
- **Генерация 4-значного PIN** при успешной активации ключа
- **Вход по PIN** при последующих запусках
- **Сброс ключа** с возможностью ввести новый

### 💬 Чат с AI
- **Выбор модели** из списка доступных через API
- **Поиск моделей** по названию
- **Сохранение истории** диалогов в локальную базу данных SQLite
- **Экспорт истории** в JSON-файл
- **Отображение баланса** провайдера

### 📊 Аналитика
- **Статистика использования**: количество сообщений, токенов
- **Средние показатели**: токенов на сообщение, сообщений в минуту
- **История аналитики** сохраняется в локальную БД

## 🚀 Установка и запуск

### Предварительные требования

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (версия 3.11+)
- [Dart SDK](https://dart.dev/get-dart) (версия 3.11+)
- iOS Simulator (macOS) или Android Emulator
- Ключ API от [VSEGPT](https://vsegpt.ru) или [OpenRouter](https://openrouter.ai)

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/ai-chat.git
cd ai-chat
```

### 2. Настройка окружения

Создайте файл `assets/.env` и укажите ваш API-ключ (опционально, для разработки):

```env
OPENROUTER_API_KEY=sk-or-vv-ваш_ключ
BASE_URL=https://api.vsegpt.ru/v1
```

> **Важно**: Файл `.env` добавлен в `.gitignore` и не будет отправлен в репозиторий. При первом запуске ключ вводится через интерфейс приложения.

### 3. Установка зависимостей

```bash
flutter pub get
```

### 4. Запуск приложения

```bash
# Запуск на iOS симуляторе
flutter run

# Запуск на Android эмуляторе
flutter run -d emulator-5554

# Запуск в веб-режиме (ограниченная поддержка)
flutter run -d chrome
```

### 5. Сборка для публикации

```bash
# iOS
flutter build ios --release

# Android
flutter build apk --release
```

## 📡 API Endpoints

### VSEGPT (`https://api.vsegpt.ru/v1`)

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/models` | GET | Список доступных моделей |
| `/balance` | GET | Получение баланса аккаунта |
| `/chat/completions` | POST | Отправка сообщения модели |

### OpenRouter (`https://openrouter.ai/api/v1`)

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/models` | GET | Список доступных моделей |
| `/auth/key` | GET | Информация о ключе (баланс, лимиты) |
| `/chat/completions` | POST | Отправка сообщения модели |

## 📁 Структура БД

### `auth.db` — таблица `auth`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Первичный ключ |
| `api_key` | TEXT | API-ключ |
| `pin` | TEXT | 4-значный PIN |
| `provider` | TEXT | Провайдер (`vsegpt` / `openRouter`) |
| `base_url` | TEXT | Базовый URL API |

### `chat_cache.db` — таблица `messages`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Первичный ключ |
| `model` | TEXT | Использованная модель |
| `user_message` | TEXT | Сообщение пользователя |
| `ai_response` | TEXT | Ответ AI |
| `timestamp` | TEXT | Временная метка |
| `tokens_used` | INTEGER | Потраченные токены |
